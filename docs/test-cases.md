# Тест-кейсы

Ручные проверки, выполненные в 1С:Предприятие 8.5 (учебная версия).

## Продажи и склад

| ID | Сценарий | Шаги | Ожидаемый результат |
|---|---|---|---|
| TC-001 | Продажа в пределах остатка | Реализация на 1 шт. товара, которого есть 3 | Документ проведён, остаток уменьшился на 1 |
| TC-002 | Продажа в минус | Реализация на 5 шт., остаток 2 | Отказ «Не хватает товара…», остаток не изменился |
| TC-003 | Продажа товара с нулевым остатком | Реализация на 1 шт. товара с остатком 0 | Отказ «Не хватает товара…» |
| TC-004 | Автоподстановка цены | Выбрать товар в строке | Цена = цена продажи из справочника, сумма = цена × количество |
| TC-005 | Реализация на основании заказа | Создать заказ, «Создать на основании» → «Реализация товаров», провести | Поля заполнены из заказа, статус заказа стал «Выполнен» |
| TC-006 | Отказ в проведении не меняет заказ | Заказ на количество больше остатка, провести реализацию на его основании | Отказ «Не хватает товара…», статус заказа остался «Новый» |
| TC-007 | Повторная реализация по одному заказу | Вторая реализация на основании уже выполненного заказа, провести | Отказ «По этому заказу уже есть проведённая реализация», остатки не изменились (дефект найден при ручном тестировании и исправлен) |

## Закупки

| ID | Сценарий | Шаги | Ожидаемый результат |
|---|---|---|---|
| TC-008 | Поступление на основании заказа поставщику | Создать заказ поставщику, «Создать на основании» → «Поступление товаров», провести | Поля заполнены из заказа, остатки увеличились |
| TC-009 | Повторное поступление по одному заказу | Вторая приёмка на основании того же заказа, провести | Отказ «По этому заказу поставщику уже есть проведённое поступление» |

## Взаиморасчёты

| ID | Сценарий | Шаги | Ожидаемый результат |
|---|---|---|---|
| TC-010 | Долг покупателя после реализации | Провести реализацию на 1000 ₽ | В отчёте «Взаиморасчёты» покупатель в колонке «Долг нам» +1000 |
| TC-011 | Частичная оплата от покупателя | Оплата от покупателя на 400 ₽ | Долг покупателя уменьшился на 400 |
| TC-012 | Полная оплата | Оплатить весь остаток долга покупателя | Покупатель пропал из отчёта |
| TC-013 | Долг перед поставщиком | Провести поступление на 500 ₽ | Поставщик в колонке «Мы должны» на 500 больше |
| TC-014 | Оплата поставщику | Оплата поставщику на 500 ₽ | Долг перед поставщиком уменьшился на 500 |
| TC-015 | Отказ реализации не создаёт долг | Реализация на количество больше остатка | Отказ «Не хватает товара…», долг покупателя не изменился |
