# Тест-кейсы

Ручные проверки, выполненные в 1С:Предприятие 8.5 (учебная версия) и на сайте-витрине.

## Продажи и склад

| ID | Сценарий | Шаги | Ожидаемый результат |
|---|---|---|---|
| TC-001 | Продажа в пределах остатка | Реализация на 1 шт. товара, которого есть 3 | Документ проведён, остаток уменьшился на 1 |
| TC-002 | Продажа в минус | Реализация на 5 шт., остаток 2 | Отказ «Не хватает товара…», остаток не изменился |
| TC-003 | Продажа товара с нулевым остатком | Реализация на 1 шт. товара с остатком 0 | Отказ «Не хватает товара…» |
| TC-004 | Автоподстановка цены | Выбрать товар в строке | Цена = цена продажи из справочника, сумма = цена × количество |
| TC-005 | Реализация на основании заказа | Создать заказ, «Создать на основании» → «Реализация товаров», провести | Поля заполнены из заказа, статус заказа стал «Выполнен» |
| TC-006 | Отказ в проведении не меняет заказ | Заказ на количество больше остатка, провести реализацию на его основании | Отказ «Не хватает товара…», статус заказа остался «Новый» |
| TC-007 | Повторная реализация по одному заказу | Вторая реализация на основании уже выполненного заказа, провести | Отказ «По этому заказу уже есть проведённая реализация», остатки не изменились (дефект найден при ручном тестировании и исправлен) |

## Сайт-витрина

| ID | Сценарий | Шаги | Ожидаемый результат |

| TC-017 | Остаток обновляется после проведения | Провести в 1С поступление, обновить страницу сайта | Остаток товара на сайте вырос на проведённое количество |
| TC-018 | Фильтр «Только в наличии» | Включить переключатель | Остаются только товары с остатком больше 0, счётчик «Показано N из M» меняется |

| TC-021 | 1С недоступна | Отключить публикацию или поменять адрес `ONEC_BASE_URL` | Сайт не падает, показывает сообщение «Каталог временно недоступен», в консоли записана причина |
| TC-022 | Проверка связи | Открыть `/health` при работающей и при недоступной 1С | `{"status":"ok"}` и ответ 503 соответственно |
| TC-023 | Товар без фото | Товар без файла в `static/img` | Вместо фото показана заглушка категории |
