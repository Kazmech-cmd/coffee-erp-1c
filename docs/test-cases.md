# Тест-кейсы: реализация товаров

| ID | Сценарий | Шаги | Ожидаемый результат |
|---|---|---|---|
| TC-001 | Продажа в пределах остатка | Реализация на 1 шт. товара, которого есть 3 | Документ проведён, остаток уменьшился на 1 |
| TC-002 | Продажа в минус | Реализация на 5 шт., остаток 2 | Отказ с текстом «Не хватает товара…», остаток не изменился |
| TC-003 | Продажа товара с нулевым остатком | Реализация на 1 шт. товара с остатком 0 | Отказ с текстом «Не хватает товара…» |
| TC-004 | Автоподстановка цены | Выбрать товар в строке | Цена = цена продажи из справочника, сумма = цена × количество |
